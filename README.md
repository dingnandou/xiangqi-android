# 掌上象棋 2.2

离线安卓象棋游戏：先在主界面选择模式与难度，再开始对局。支持人机对战、同机双人、AI 对战 AI 观战、提示、悔棋、重开、认输和自动存档。

## 安装

[下载掌上象棋.apk](output/掌上象棋.apk)，约 52 MB。支持 Android 8.0 及以上的 64 位 ARM 手机；安装包也包含 x86_64 测试版本。

把 APK 发到手机后点击安装。2.2 与之前版本使用相同签名，可以覆盖安装并保留旧棋局。无需登录或联网。

## 主界面与对局

![主界面](output/主界面.png)

- 人机对战：你执红，手机执黑。
- 同机双人：两个人轮流操作同一部手机。
- AI 观战：双方自动走棋，支持暂停、下一步和速度调整。
- 继续上局：保留原棋局与难度，首页的新局设置不会覆盖它。
- 设置：落子震动；玩法说明与关于。

四档难度为简单、普通、困难、大师。简单与普通使用轻量本地对手；困难与大师使用 Pikafish 专业引擎。大师是本游戏的最高档，不代表正式赛事棋力评级。

![棋盘界面](output/手机界面.png)

棋盘显示轮走方、双方信息、已吃棋子数、回合和上一着。支持合法落点、将军、将死、困毙、提示与悔棋。返回首页或退出游戏都会保存；观战会自动暂停。

2.2 修正棋字居中，并直接使用效果图中的红黑书法字形，避免系统字体回退或小字号放大造成偏移。木质棋子使用参考图风格的透明素材，保留圆润倒角、高光与投影；双方头像与首页装饰采用同一绘制器。详见 [棋子素材说明](docs/棋子素材说明.md)。

## 构建与验证

源码在 `app/src/main/java/com/yijin/xiangqi/light`；新原生桥接在 `app/src/main/cpp`，Pikafish 对应源码在 `engine/src/main/cpp/pikafish`。

运行 `tools/build-phone-apk.ps1`，会编译 arm64-v8a/x86_64 引擎并生成签名 APK。需要 JDK 17、Android SDK 36、build-tools 36.0.0、NDK 28.2.13676358、CMake 3.22.1。

检查脚本：`tools/ChessChecks.java`、`tools/check-home-ui.ps1`、`tools/check-phone-ui.ps1`、`tools/check-watch-ui.ps1`、`tools/check-piece-centering.ps1`。棋字检查从实际截图测量文字边界；安卓交互脚本仅用于可 root 的临时测试模拟器，会清除测试应用存档。
